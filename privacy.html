Politique de confidentialité / Privacy policy

Dernière mise à jour / Last updated : 4 octobre 2026

Français

1. Qui est concerné

Agent perso est une application personnelle à utilisateur unique : son auteur. Aucun autre utilisateur n'a accès à l'application. Cette politique décrit comment elle traite les données du compte Google de son auteur.

2. Données auxquelles l'application accède

Avec l'autorisation explicite de son auteur, via Google OAuth, l'application peut lire, depuis la Google Health API : les données d'activité et de forme physique, les mesures et indicateurs de santé, les données de sommeil, ainsi que les données de nutrition, de localisation d'exercices, de pleine conscience, de symptômes enregistrés et de santé reproductive. Ces dernières catégories ne sont consultées que si l'auteur en fait la demande.

À ce jour, l'application n'écrit, ne modifie et ne supprime aucune donnée dans Google Health.

3. Utilisation des données

Les données sont lues à la demande de l'auteur, ou lors d'un bilan automatique, pour produire des synthèses personnelles (par exemple un bilan du matin sur le sommeil et l'activité). Elles ne servent à aucune autre finalité : ni publicité, ni profilage, ni revente.

Pour produire ces synthèses, un extrait des données peut être transmis, par interface de programmation (API), à un fournisseur de modèle de langage. Cette transmission se limite au contenu nécessaire à la demande en cours. L'auteur n'utilise pas ces données pour entraîner de modèles d'intelligence artificielle.

4. Stockage et sécurité

Les identifiants d'accès (jetons OAuth) sont stockés sur le serveur personnel de l'auteur, dans un fichier à accès restreint. Les données lues peuvent être conservées temporairement sur ce même serveur. Elles ne sont pas transmises à un service de stockage tiers. Aucune autre personne n'y a accès.

5. Partage

Aucune donnée n'est vendue, louée ni partagée avec des tiers, à l'exception de la transmission technique décrite au point 3.

6. Conformité Google

L'utilisation et le transfert vers toute autre application des informations reçues des API Google respectent la Politique relative aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée (« Limited Use »).

7. Suppression et retrait de l'accès

L'auteur peut à tout moment retirer l'accès de l'application depuis son compte Google (myaccount.google.com/permissions) et supprimer les jetons et données stockés sur son serveur. Contact : richard.bonrodr@gmail.com

8. Modifications

English

1. Scope

Agent perso is a single-user personal application; its only user is its author. No other user has access to it. This policy describes how it handles data from the author's own Google account.

2. Data accessed

With the author's explicit consent through Google OAuth, the application may read from the Google Health API: activity and fitness data, health metrics and measurements, sleep data, as well as nutrition, exercise location, mindfulness, logged symptoms and reproductive health data. These latter categories are accessed only when the author explicitly requests it.

As of today, the application does not write, modify or delete any data in Google Health.

3. How data is used

Data is read on the author's request, or for an automatic summary, to produce personal summaries (for example a morning report on sleep and activity). It is never used for advertising, profiling or resale.

To produce these summaries, an excerpt of the data may be sent, through an API, to a language-model provider. This is limited to what the current request requires. The author does not use this data to train artificial intelligence models.

4. Storage and security

OAuth tokens are stored on the author's own server in a file with restricted access. Data that is read may be kept temporarily on that same server. It is not sent to any third-party storage service. No other person has access to it.

5. Sharing

No data is sold, rented or shared with third parties, other than the technical transmission described in section 3.

6. Google API Services User Data Policy

Agent perso's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Deletion and revoking access

The author can revoke access at any time at myaccount.google.com/permissions and delete the tokens and data stored on the server. Contact: richard.bonrodr@gmail.com
